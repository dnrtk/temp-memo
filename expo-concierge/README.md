# 展示会ブース用 AIコンシェルジュ(ブラウザ版)

ブラウザで開いて F11 で全画面にするだけの構成。インストールは不要(Python 3 だけあればよい。標準ライブラリしか使わない)。

```
ブラウザ ── http://localhost:8000 ── serve.py ──▶ GRYPHON (/v1/chat-messages, SSE)
                                             └─▶ AivisSpeech (/v1/audio/speech/events, NDJSON)
```

## 起動

1. `start.bat` の先頭3行(GRYPHON の URL、APIキー、TTS の URL)を書き換える
2. `start.bat` をダブルクリック → ブラウザが開くので F11
3. 来場者が最初に画面に触れたときから声が出る(ブラウザの仕様で、触れるまでは音が鳴らない)

バックエンドなしで画面と動きだけ確認したいときは `start-mock.bat`。動作ログ付きで開く。

`?debug` を付けて開く(`http://localhost:8000/?debug`)と、画面左下に動作ログが出る。GRYPHON の最初の文字が届くまでの時間と、文ごとに「キャッシュ」か「生成」か、音声が届くまでの時間が出る。serve.py の画面にも文ごとの生成時間が出る。

### serve.py を挟んでいる理由

ブラウザから GRYPHON と TTS サーバを直接呼ぶと、両方のサーバが CORS ヘッダを返さない限りブロックされる。さらに APIキーがページに載ってしまう。serve.py がページの配信と中継を同じオリジンで行うので、どちらも気にしなくてよくなる。

両方とも CORS を返す設定にできるなら、serve.py なしでも動く。`config.js` の `baseUrl` を実際の URL にして、`index.html` を直接開く。

## 設定 (config.js)

| キー | 内容 |
|---|---|
| `tts.params` | 合成リクエストに毎回付ける値(既定は空 = サーバ既定の `阿井田 茂` / `Heavy`)。例: `{ speaker: 'まお', style: 'おちつき', speed: 1.0 }`。使える声は `GET /v1/audio/speech/models` |
| `tts.split` | サーバ側の区切り方。`sentence`(既定)/ `clause`(読点でも区切る。声が出るまでは速いが抑揚が不自然になりやすい) |
| `tts.streaming` | `true`(既定)= `/events` で文ごとに再生 / `false` = `/v1/audio/speech` で一括 |
| `ui.layout` | `bubble`(吹き出し)/ `panel` |
| `ui.brandName` / `ui.boothTitle` / `ui.assistantName` / `ui.accent` | 表記とアクセント色 |
| `presets` | よくある質問のボタン(6個前後) |

それ以外の項目(待機画面の文言、無操作で最初に戻るまでの秒数、つなぎの一言、読み上げの上限文字数など)は `app.js` 冒頭の `DEFAULTS` にある。`config.js` に同じ形で書けば上書きできる。

## 回答の長さ(プロンプト)

音声合成に時間がかかるので、回答は「2〜3文・100字程度・結論から・です・ます調」に絞らせている。

- `prompts/system-prompt.md`: GRYPHON の LLM ノードのシステムプロンプト、または Copilot Studio エージェントの指示に貼る本番用
- `prompts/answer-rules.txt`: 同じ方針の短い版。`config.js` の `gryphon.answerRulesMode` が `'append'`(既定)のときは、これを質問文の末尾に付けて送る。サーバ側を触らなくても効く
- システムプロンプトに入れ終わったら `answerRulesMode` を `'off'` にする。チャットフロー側で変数として受けたいときは `'inputs'` にする(`inputs.answer_rules` に入る)
- 締めの「詳しくはブーススタッフにお尋ねください。」は起動時に合成しておくので、ブラウザのメモリから即座に鳴る

## Thinking(推論)モデルの出力

`<think>…</think>` / `<thinking>` / `<reasoning>` と、Dify 系の `<details><summary>Thinking…</summary>…</details>` の中身は、画面にも音声にも出さない。ストリームの途中でタグが切れていても判定する。開始タグなしで `</think>` だけが来るモデルでは、それまでに出た分を考え中だったとみなして消す。

## 読み上げ(AivisSpeech)とキャッシュ

- TTS は AivisSpeech(既定 `http://127.0.0.1:8082`)。ブラウザは serve.py の `/tts/v1/audio/speech/events` を呼び、文ごとに届いた音声から順に鳴らす
- 回答はストリーミングで届くたびに文単位に切り、短い文はまとめ、長い文は読点で切って送る
- 無音から鳴り始めるときは `tts.prebufferMs`(既定 800ms)だけ待ってから鳴らし、続きの文の合成が間に合うようにする。キャッシュから届いた音声は待たない
- 回答のテキストは、その部分を話し始めたときから1文字ずつふわっと出す(全文が届いていても同じ)。速さは `ui.typeCharsPerSec`(既定 40文字/秒。発話の速さには合わせない)、ふわっと出る時間は `ui.fadeMs`(既定 700ms、0 でなし)
- 「確認しますので、少々お待ちください。」は、質問から `voice.ackDelayMs`(既定 1500ms)以内に回答の最初の文を読み上げに回せたときは言わない(キャッシュに当たる回答や、すぐ返る回答のとき)
- 質問を受けてから答え終わるまでは、`tts-phrases.txt` の事前合成を止めて TTS サーバを空けておく
- 読み上げに合わせるのをやめるときは `voice.syncText: false`(届いたらすぐ出す)。声が出るまでは「考え中」の表示のまま。読み上げを止めたとき、上限文字数で読み上げを打ち切ったとき(「続きは画面で」を話し始めたとき)、読み上げが終わったときは、残りを全部出す
- 次の質問・停止・リセットでは接続を切るので、残りの文は合成しない
- 一括の `/v1/audio/speech`(WAV)に戻したいときは `config.js` の `tts` に `streaming: false` を書く(この場合キャッシュは効かない)

### キャッシュ(serve.py)

AivisSpeech は 1 秒の音声に 1.5〜2 秒ほどかかるため、合成しながら読み上げると文の間に空白ができる。そこで serve.py が文ごとの音声を `tts-cache/` に保存し、同じ文は合成せずに返す(実測 0.01 秒)。

- キーは「文 + 声のパラメータ(`config.js` の `tts.params`)」。声の設定を変えると別の音声として合成し直しになる
- serve.py を再起動しても残る。`tts-cache/index.jsonl` に、どの文を保存したかが書いてある。消したいときはフォルダごと削除する
- モック(`--mock`)のときは `tts-cache-mock/` を使う。`--cache-dir` で保存先の変更、`--no-cache` で無効化ができる

### よく出る文を事前に合成しておく

`tts-phrases.txt` に 1 行 1 つ書いておくと、画面を開いている間、読み上げていないときに上から順に合成してキャッシュに入れる(合成済みの行はすぐ終わる)。来場者への読み上げが始まると途中で止め、後でやり直す。

- よくある質問の回答を GRYPHON 側でなるべく固定文にし、その文を書いておく
- 同じ言い回しを毎回使うよう、システムプロンプトで回答のテンプレートを決めておく(例: 「〜については、ブース奥のデモ機でお試しいただけます。」で締める)
- 決まり文句(「確認しますので、少々お待ちください。」「続きは画面でご覧ください。」、エラー時の案内、`voice.warmPhrases`)は起動時に合成し、ブラウザのメモリにも置いておく
- 回答の最初の文を読点で早めに切って先に鳴らす処理(`voice.firstSegmentCut`)は、既定でオフにしている。オンにすると声が出るのは早くなるが、その文はキャッシュに当たらなくなる

## 展示会当日のチェック

- F11 の全画面は、マウスを画面上端に持っていくとタブバーが出る。気になるなら Chrome をキオスクモードで起動する: `chrome.exe --kiosk --autoplay-policy=no-user-gesture-required http://localhost:8000/`(この起動方法なら、最初に触れなくても声が出る)
- Windows のタッチキーボード: 設定 >「タッチキーボード」を「キーボードが接続されていないとき」に表示
- 省電力・スリープ・Windows Update の再起動はオフにしておく
- 回線が不安定なときは、画面と音声でスタッフ案内のメッセージになる。予備回線もあると安心
